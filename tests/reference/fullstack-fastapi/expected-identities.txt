# WHAT THIS FILE IS. Identities an FDE would name from memory after ten minutes
# in this repository. `adopt map --check-expected` asserts every one is present
# and names each miss, exiting 4 on any.
#
# WHY IT IS CURATED RATHER THAN A COVERAGE RATIO. A recall percentage over a
# golden corpus invites denominator games -- it improves when the denominator
# shrinks. A named list cannot: either `POST /login/access-token` is in the map
# or it is not, and the failure names it. The list grows when an FDE notices an
# omission, and **each miss becomes an entry here before it becomes a fix**.
#
# WHAT IS DELIBERATELY ABSENT. Paths are relative to their mount point: this
# application mounts its API under `settings.API_V1_STR`, a variable whose value
# needs the client's configuration executed to resolve, which `adopt map` will
# never do. So `/login/access-token` appears here, not `/api/v1/login/access-token`.
# That boundary is stated rather than hidden -- see `_router_prefixes` in
# `adopt_map.packs.web` for what is and is not statically decidable.
